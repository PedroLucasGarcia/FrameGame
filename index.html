Carregando o filme do dia…
FrameGame #1

      Um filme novo todo dia. Imagens: TMDB. Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.

      Como jogar

      Será que você consegue acertar o filme vendo apenas uma imagem?

      • Você tem 6 chances para adivinhar o filme.
      • A cada erro ou pulo, uma nova imagem é revelada.
      • Um filme novo é liberado todo dia à meia-noite (horário de Brasília).
      • Perdeu algum dia? Jogue os filmes anteriores no arquivo.
      • Seu progresso fica salvo neste navegador.
